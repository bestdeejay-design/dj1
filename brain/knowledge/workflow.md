# Рабочий процесс создания музыки (воркфлоу движка)

> Наследие: chats-audit/music/AI_MUSIC_WORKFLOW.md, адаптировано под
> конвейер dj1 brain: LLM пишет промт и лирику, ACE-Step генерирует музыку.

## Роли инструментов

| Уровень | Инструмент | Что делает |
|---|---|---|
| Мозг | LLM + `brain/` (этот репозиторий) | Концепция, теги, лирика — по правилам и корпусу опыта |
| Генератор | **ACE-Step** (+ LoRA на личном стиле) | Генерация трека из тегов и лирики |
| Прошлое | FUZZ-0.8…2.0 через Riffusion | 8202 трека корпуса — база личного опыта |
| Альтернативы (облако) | Suno, Udio, ProducerAI | Сравнение качества, форматы совместимы |

## Стандартный цикл

1. **Запрос** — поймать идею пользователя (жанр, настроение, тема, язык).
2. **Контекст из мозга** — подобрать по `corpus/tracks.jsonl` близкие
   удачные треки (score, жанр, BPM), взять эталоны из `libraries/`.
3. **Теги (PROMPT)** — по правилам `prompt-rules.md`; негативы
   перефразировать позитивно под ACE-Step.
4. **Лирика (LYRICS)** — по структуре `song-structure.md`.
5. **Генерация** — ACE-Step, TITLE / LYRICS / PROMPT.
6. **Прослушивание** — оценить: жанр совпал? темп? вокал? язык?
7. **Итерация** — подправить теги/лирику (обычно 1–2 итерации);
   треки-неудачи тоже фиксируем — что именно не сработало.
8. **Сохранение** — удачный результат: теги+лирика добавляются в корпус
   (`corpus/`), трек — в продакшн (dj1/dajet).

## Формат запроса (стандарт проекта)

```
TITLE
<название трека>

LYRICS
<полный текст с метками секций>

PROMPT
<теги ACE-Step>
```

## Типичные проблемы и решения

| Проблема | Решение |
|---|---|
| Модель игнорирует язык лирики | Добавить тег `Russian lyrics` в PROMPT |
| Неверный темп | Указать BPM явно: `120 BPM` |
| Слишком общий звук | Добавить конкретные инструменты из `style-taxonomy.md` |
| Лирика «плывёт» | Разбить на чёткие секции с метками |
| Нет нужного инструмента | Первым тегом: `featuring piano` |
| Повторяющийся результат | Изменить ключевые теги, добавить `variation`, сменить seed |
| «Родной стиль» не чувствуется | Учесть LoRA-адаптер (см. `model-acestep.md`) |
| Промт с запретами (`no X`) | Перефразировать позитивно (`male vocals only`) |

## Чек-лист качества промта

- [ ] Жанр и поджанр (по таксономии `style-taxonomy.md`)
- [ ] Инструменты (конкретно)
- [ ] Темп (BPM)
- [ ] Вокал (пол, стиль, язык лирики)
- [ ] Настроение (1–3 дескриптора)
- [ ] Эпоха/продакшн (если нужен характер)
- [ ] Нет имён исполнителей и брендов
- [ ] Нет негативных формулировок
- [ ] Блоки TITLE / LYRICS / PROMPT разделены

## Цикл накопления опыта (как мозг учится)

```
ACE-Step сгенерировал трек -> прослушивание -> оценка (plays/favorites)
   -> трек попадает в продакшн -> выгрузка в data/tags-data.json
   -> python3 brain/tools/build_corpus.py  (корпус обновился)
   -> python3 brain/tools/stats.py          (статистика обновилась)
   -> python3 brain/tools/build_libraries.py && build_datasets.py
   -> LoRA-датасет растёт -> переобучение адаптера
```

Все четыре инструмента идемпотентны: запускай после каждой выгрузки
из api.dj1.ru — мозг всегда синхронен с реальным опытом.
