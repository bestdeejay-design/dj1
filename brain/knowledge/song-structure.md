# Структура песни для ИИ-генерации

> Наследие: chats-audit/music/SONG_STRUCTURE.md (без изменений по сути;
> формат меток совместим с ACE-Step).

## Стандартные секции

| Метка | Назначение | Типичная длина |
|-------|-----------|----------------|
| `[Intro]` | Инструментальное вступление, задаёт атмосферу | 4–8 тактов |
| `[Verse]` / `[Verse 1]` | Куплет — развитие сюжета/образа | 4–8 строк |
| `[Pre-Chorus]` | Переход, нарастание к припеву | 2–4 строки |
| `[Chorus]` | Припев — эмоциональный центр, повторяется | 4–8 строк |
| `[Bridge]` | Контрастная секция, смена гармонии/настроения | 4–8 строк |
| `[Break]` / `[Drop]` | Инструментальный разрыв (для электроники) | 4–8 тактов |
| `[Outro]` / `[Fade Out]` | Завершение, затухание | 4–8 тактов |
| `[Spoken]` | Разговорная вставка | 1–4 строки |
| `[Hook]` | Короткий запоминающийся мотив | 1–2 строки |

## Типовые структуры

### Поп / Рок
```
[Intro] → [Verse 1] → [Pre-Chorus] → [Chorus] → [Verse 2] → [Pre-Chorus] → [Chorus] → [Bridge] → [Chorus] → [Outro]
```

### Электроника / Техно-хаус
```
[Intro] → [Drop] → [Verse] → [Build-up] → [Drop] → [Break] → [Drop] → [Outro]
```

### Баллада / Романс
```
[Intro] → [Verse 1] → [Chorus] → [Verse 2] → [Chorus] → [Bridge] → [Chorus] → [Outro]
```

### Психоделический / Эмбиент
```
[Intro] → [Verse] → [Chorus] → [Verse] → [Bridge] → [Outro (fade)]
```

## Правила разметки

1. Каждая секция начинается с метки в квадратных скобках на отдельной строке.
2. Звуковые эффекты — в квадратных скобках внутри секции: `[vinyl crackle]`,
   `[whispered]`.
3. Бэк-вокал / адлибы — в круглых скобках: `(ooh)`, `(backing: yeah)`.
4. Повторяющиеся секции пишутся полностью (не используйте `(x2)`).
5. Припев повторяется минимум 2 раза (обычно 3).
6. Бридж — один на трек, контрастный по гармонии и тексту.

## Пример размеченной лирики

```
[Intro: Rain, vinyl crackle, whispered close-mic, echo fade]

[Verse 1: Soft piano, ambient rain, calm conversational flow]
В кафе я каждый вечер тут
Стакан вина, мой верный друг
Смотрю на улицы Парижа
Дождь стучит, я слышу, слышу

[Pre-Chorus: Synth swell, heartbeat bass, dreamy delivery]
В отражении витрин
Светит свет, бегут огни

[Chorus: Full arrangement, soaring vocals, reverb tail]
Сквозь дождь я вижу твои тайны
Сквозь дождь я слышу твои шаги

[Bridge: Minimal, spoken-word, stripped back]
Если бы я мог остановить время...

[Outro: Fade, vinyl crackle, rain]
Дождь... дождь...
```
