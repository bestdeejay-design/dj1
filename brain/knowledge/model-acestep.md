# Модель ACE-Step — технический паспорт для движка

> Рабочая модель конвейера dj1 brain. Здесь — проверенные факты, формат входа
> и ограничения. Все ссылки — первоисточники.

## Что это

**ACE-Step** — открытая фундаментальная модель генерации музыки
(text-to-music), совместно разработанная ACE Studio и StepFun.
Лицензия Apache 2.0 (свободное коммерческое использование).

- Репозиторий: https://github.com/ace-step/ACE-Step
- Веса: https://huggingface.co/ACE-Step/ACE-Step-v1-3.5B
- Проект/демо: https://ace-step.github.io
- Техотчёт: arXiv 2506.00045

Версии:
- **v1** (май 2025) — 3.5B, diffusion-трансформер + DCAE-аудиокодек
  (Sana Deep Compression AutoEncoder) + линейный трансформер; до 4 минут
  музыки за ~20 секунд на A100; оптимизация до 8 ГБ VRAM
  (`--cpu_offload true --overlapped_decode true`) — запуск на
  потребительских GPU.
- **v1.5** (январь 2026) — актуальная мажорная версия; улучшенное качество,
  официально поддерживаемый LoRA-файнтюн
  (`docs/en/LoRA_Training_Tutorial.md` в репозитории модели).

Возможности помимо text-to-music: репейнтинг/продолжение трека,
voice cloning, lyric editing, remix, lyric2vocal, singing2accompaniment,
Audio2Audio; есть нода ComfyUI.

## Формат входа

Модель принимает два поля:

1. **Теги / описание стиля** (caption). Три допустимых формата:
   - короткие теги через запятую: `tech house, female vocals, 126 BPM, dark`;
   - описательный текст: `hypnotic tech house with velvet female vocal...`;
   - сценарий использования: `closing track of an afterparty set`.
2. **Лирика** (опционально, для вокальных треков) — с метками секций.

### Языки

Поддерживается 19 языков; топ-10 по качеству: английский, китайский,
**русский**, испанский, японский, немецкий, французский, португальский,
итальянский, корейский. Реже встречающиеся языки могут работать хуже
(дисбаланс данных).

## Отличия от FUZZ/Riffusion (наш прошлый стек)

Все 8202 трека корпуса сгенерированы на линейке FUZZ-0.8 … FUZZ-2.0
через Riffusion. При переносе промтов на ACE-Step:

| Особенность | FUZZ/Riffusion | ACE-Step |
|---|---|---|
| Длина промта | короткий, до ~500 символов | теги или текст, разумно ≤ 250 символов на теги |
| Негативные указания | `no falsetto`, `no climax` работали | негативного поля нет — **перефразировать позитивно** |
| Лирика | отдельно, по сути текст | поддерживается нативно, с разметкой секций |
| Разброс результатов | широкий | управляется seed/cfg, предсказуемее |

### Перефразирование негативов (важно!)

Промты корпуса часто содержат запреты (топ-5 по корпусу: `no vocals`,
`no female vocals`, `no climax`, `no melody`, `no reverb`). Для ACE-Step
каждый запрет переводим в утверждение:

- `no female vocals` → `male vocals only`
- `no climax` → `steady energy, no big build-ups` → лучше `flat dynamics, loop-like`
- `no reverb` → `dry, close-mic production`
- `no falsetto` → `full-voice baritone delivery`

## LoRA-файнтюн на личном стиле

ACE-Step поддерживает обучение LoRA-адаптеров на собственных треках —
это способ «встроить» личный опыт в модель.

- Руководства: `TRAIN_INSTRUCTION.md`, `ZH_RAP_LORA.md` (v1);
  `docs/en/LoRA_Training_Tutorial.md` (v1.5).
- Типичный датасет: папка `dataset/audio/` + metadata с caption на каждый
  трек (жанр, инструменты, темп, настроение — наш формат уже даёт это
  в `brain/datasets/lora-candidates.jsonl`, поле `caption`).
- Ориентиры сообщества: 20–50 сильных треков достаточно для стилевого
  адаптера; сегменты фиксированной длины (например, 45 секунд); качество
  caption напрямую влияет на результат.
- Требования к железу: от 8 ГБ VRAM (как и инференс).

Полный чек-лист сборки датасета — `brain/datasets/README.md`.

## Как модель связана с мозгом

```
Пользовательский запрос
        |
        v
   brain (LLM + knowledge/ + corpus/ + libraries/)   <- этот репозиторий
        |  TITLE / LYRICS / PROMPT (теги)
        v
   ACE-Step (+ LoRA на личном стиле)  -> трек -> продакшн (dj1/dajet)
```

Знания (`knowledge/`) говорят LLM, КАК писать промты и лирику;
корпус (`corpus/`) даёт статистику и примеры «что уже сработало»;
библиотеки (`libraries/`) — готовые эталоны; датасеты (`datasets/`)
переносят личный стиль в веса модели.
