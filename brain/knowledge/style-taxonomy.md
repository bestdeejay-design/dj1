# Таксономия стилей (чистая)

> Единый словарь тегов движка. Основан на реальном распределении корпуса
> (8202 трека, срез 2026-03-12, счётчики — `corpus/stats.md`).
> Зачем: старая таксономия dj1 (9 категорий в data/tags-data.json) была
> фрагментирована на слова («deep» и «house» отдельно, «tech» как жанр);
> здесь — целые жанры и согласованный словарь.

## Как устроен тег-капсион ACE-Step

```
<жанр>[, <поджанр>], <инструменты 2–5>, <вокал>, <BPM>, <настроение 1–3>[, <эпоха>][, <продакшн>]
```

Пример: `tech house, analog synth, sub bass, female vocals, 126 BPM, dark,
hypnotic, 90s, tape saturation`

## 5. Темп (BPM)

- Диапазон корпуса: 33–180, медиана **128**.
- BPM распознан у 40% треков; типичные зоны: 60–100 (downtempo/lo-fi),
  100–130 (house/pop), 130–145 (trance/techno), 145–180 (drum and
  bass/hardstyle).
- В тегах указывать явно: `128 BPM`.

## Правила использования

1. Теги берем только из этого словаря (или расширяем словарь в
   `tools/build_corpus.py` — не изобретаем на лету).
2. Порядок в капсионе: жанр → инструменты → вокал → BPM → настроение →
   эпоха → продакшн.
3. Жанров 1–3, инструментов 2–5, настроений 1–3.
4. Всё позитивно: вместо `no reverb` пишем `dry, close-mic production`.
5. Сверяться со счётчиками: редкие теги (менее ~20 треков в корпусе)
   использовать осторожно — опыта по ним мало.
