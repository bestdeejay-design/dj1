# runs/ — прогоны мозга

Прогон — это реальный цикл конвейера: запрос → мозг → тройка
**TITLE / LYRICS / PROMPT** в формате ACE-Step. Прогоны фиксируются файлами,
чтобы видеть, как меняется качество генерации по мере роста корпуса
и уточнения правил.

## Формат файла прогона

- имя: `YYYY-MM-DD-run-NN.md` (одна нумерация на день);
- шапка: какие знания/эталоны использованы;
- сводная таблица: жанр, BPM, вокал, язык, эталоны из корпуса;
- для каждого запроса: сам запрос + fenced-блок с TITLE / LYRICS / PROMPT
  (формат — `../knowledge/workflow.md` §«Формат запроса»);
- в конце — раздел «Результат валидации», его пишет валидатор.

## Валидация

```bash
python3 brain/tools/validate_run.py brain/runs/<файл>.md
```

Проверки — по `../knowledge/prompt-rules.md` и `../knowledge/song-structure.md`:
позитивные формулировки, порядок тегов (жанр первым), явный BPM, тег языка
лирики у вокальных треков, метки секций, припев минимум дважды, никаких
`(x3)`. Валидатор перезаписывает раздел «Результат валидации» в конце файла.
